Etiquetas de Tablas

Las tablas permiten presentar información organizada en filas y columnas. Son útiles para mostrar datos numéricos, horarios, listas comparativas, etc.

Table

Inicio de la etiqueta: < table>
Cierre de la etiqueta: < /table>
Descripción: Esta etiqueta inicia una tabla. Todas las filas y celdas deben estar dentro de esta etiqueta.

Tr

Inicio de la etiqueta: < tr>
Cierre de la etiqueta: < /tr>
Descripción: Esta etiqueta define una fila dentro de la tabla. Se colocan celdas de datos dentro de ella.

Td

Inicio de la etiqueta: < td>
Cierre de la etiqueta: < /td>
Descripción: Esta etiqueta representa una celda de datos normales. Se usa dentro de una fila.

Th

Inicio de la etiqueta: < th>
Cierre de la etiqueta: < /th>
Descripción: Esta etiqueta define una celda de encabezado, que aparece en negrita y centrada. Útil para títulos de columnas o filas.
