Etiquetas de lista

Las listas son útiles para organizar elementos de forma ordenada o desordenada. HTML ofrece dos tipos principales:

Ol

Inicio de la etiqueta: < ol>
Cierre de la etiqueta: < /ol>
Descripción: Esta etiqueta crea una lista ordenada, es decir, numerada (1, 2, 3...).

Ul

Inicio de la etiqueta: < Ul>
Cierre de la etiqueta: < /Ul>
Descripción: Esta etiqueta crea una lista no ordenada, usando viñetas o puntos.

Li

Inicio de la etiqueta: < li>
Cierre de la etiqueta: < /li>
Descripción: Esta etiqueta representa un elemento individual dentro de una lista. Se usa con ol o ul.
