Etiquetas de Formularios

Los formularios permiten recopilar datos de los usuarios, como nombre, correo electrónico, selección de opciones, entre otros. Son esenciales en páginas interactivas.

Form

Inicio de la etiqueta: < form>
Cierre de la etiqueta: < /form>
Descripción: Esta etiqueta Define el inicio de un formulario.Puede incluir campos de texto,botones, etc.

Input

Inicio de la etiqueta: < input>
Cierre de la etiqueta: no tiene
Descripción: Esta etiqueta crea un campo interactivo, como una caja de texto o botón. Su tipo se define con el atributo type.

Label

Inicio de la etiqueta: < label>
Cierre de la etiqueta: < /label>
Descripción: Esta etiqueta describe el propósito de un campo. Mejora la accesibilidad.

Select

Inicio de la etiqueta: < select>
Cierre de la etiqueta: < /select>
Descripción: Esta etiqueta crea un menú desplegable con opciones.

Option

Inicio de la etiqueta: < option>
Cierre de la etiqueta: < /option>
Descripción: Esta etiqueta define cada opción dentro de un select.
